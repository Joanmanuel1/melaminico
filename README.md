# Melamínico

Archivos finales del proyecto.

- `diseño/`: diseño de la landing page (PDF).
- `imagenes/`: material gráfico (diseñadora, Canva y capturas).
- `landing-tiendup/`: landing final para Tiendup. Los bloques listos para pegar están en `dist/`, las imágenes para subir en `subir/` y el código fuente en `src/` (se genera con `python3 build.py`).
